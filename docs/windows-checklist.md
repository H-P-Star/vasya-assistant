# Ручная проверка Windows x64

Эти сценарии требуют Windows и устройств; успешные unit-тесты не заменяют их. При проверке записывайте версию Windows, выбранный микрофон, Vosk-модель, браузер и сервис. Не отмечайте сценарий выполненным без фактического запуска.

- [ ] Установщик NSIS ставится без прав администратора. Приложение запускается, ошибка отсутствующей модели видна. Обычный браузерный предпросмотр помечен отдельно.
- [ ] `prepare-models.ps1` загружает DLL и модель. Повторный запуск не скачивает уже готовые файлы. Сохранение настроек возобновляет распознавание.
- [ ] Два запуска дают один экземпляр. Закрытие окна оставляет значок в трее. Пункт «Выход» освобождает микрофон и закрывает управляемый музыкальный браузер.
- [ ] Выбор микрофона работает. После физического отключения выбранного устройства видна ошибка. Сохранение нового выбора восстанавливает поток.
- [ ] «Вася, пауза» и «Вась, пауза» распознаются на выбранной модели. «Расскажи про Васю» без активации не выполняется. Свои wake-фразы проверены на словаре модели.
- [ ] Отдельное «Вася» открывает ожидание на 10 секунд. Команда после истечения таймаута не выполняется. Следующая команда требует новой активации.
- [ ] Режимы «только слово», «только клавиша» и «оба» соответствуют настройкам. Занятая горячая клавиша показывает ошибку, сохранённые настройки не меняются.
- [ ] Mute через UI, трей и голос освобождает устройство захвата (проверить индикатор Windows). Горячая клавиша не включает mute. В режиме только клавиши устройство свободно между командами.
- [ ] SAPI подтверждает команду, выбран русский голос. Озвучивание не вызывает следующую команду помощника. При выключении подтверждения остаётся визуальный статус.
- [ ] «Включи трек», «исполнителя», «плейлист» проверены в выбранном сервисе после входа. При отсутствии подписки, согласия или изменении DOM статус говорит о поиске, а не утверждает успешный запуск.
- [ ] Пауза и продолжение идемпотентны на текущей медиасессии Windows. Следующий трек поддерживается плеером. Громкость 0, 35, 100% и ±10% работают; значение 999 отклоняется.
- [ ] Поиск с кириллицей, `&`, `#` и кавычками открывает корректную выдачу. YouTube открывает первое видео либо явно сообщает о переходе к поиску. Проверена политика autoplay.
- [ ] Одноразовая диктовка и многофразовая диктовка работают в Блокноте, поле браузера и используемом офисном приложении. «Стоп диктовка» завершает режим и не вставляется. Та же команда в обычной диктовке не вызывает запуск музыки.
- [ ] Проверка соединения видит `google/gemma-3-4b` в LM Studio на `http://198.18.0.1:1234`. Генерация IPv6 работает. Альтернативный провайдер Ollama работает при смене адреса и модели. При выключенном сервере или неизвестной модели видна ошибка. Ввод из строки помощника показывает результат без авто-вставки.
- [ ] Во время генерации смена окна отменяет вставку, текст доступен в результате. Mute и сохранение настроек во время генерации отменяют отложенную вставку. Повторный запуск команды во время выполнения отклоняется.
- [ ] Кнопка отложенной вставки даёт 3 секунды на выбор целевого поля. Clipboard не меняется, кроме явного «Копировать». Ввод в elevated-приложение корректно отклоняется без потери результата.
- [ ] Vosk + Whisper использует локальный exe и модель; ошибочный путь выдаёт понятную ошибку. После обработки временный WAV удалён. Фраза более 30 секунд сбрасывается.
- [ ] Настройки сохраняются после перезапуска. Неверный JSON не перезаписывается автоматически. «Запускать с выключенным микрофоном» и «Открывать сразу в трее» работают.
