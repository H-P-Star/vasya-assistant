# Голос Васи

В настройках выберите движок **Windows** или **Piper**. Громкость голоса регулируется отдельно от громкости музыки и Windows. Скорость и выбранный голос можно сохранить именованным пресетом. Кнопка **Послушать голос** проверяет текущие поля до сохранения общих настроек.

## Голоса Windows

Список содержит установленные SAPI-голоса. Доступные мужские и женские голоса зависят от компонентов речи, установленных в Windows. Поле «по умолчанию» использует системный голос.

## Локальный нейросетевой голос Piper

1. Скачайте [piper_windows_amd64.zip](https://github.com/rhasspy/piper/releases/download/2023.11.14-2/piper_windows_amd64.zip) и распакуйте **весь** архив, например в `C:\VasyaVoices\piper`. Python не нужен. Это архивная самостоятельная C++-сборка; текущий проект Piper развивается отдельно.
2. Скачайте модель и её конфигурацию из одной версии каталога. Для этой сборки `piper.exe` используйте **v1.0.0**, поскольку новые конфигурации могут содержать неподдерживаемые сочетания фонем.

| Голос | Модель | Конфигурация |
|---|---|---|
| Дмитрий, мужской | [ru_RU-dmitri-medium.onnx](https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/ru/ru_RU/dmitri/medium/ru_RU-dmitri-medium.onnx) | [ru_RU-dmitri-medium.onnx.json](https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/ru/ru_RU/dmitri/medium/ru_RU-dmitri-medium.onnx.json) |
| Ирина, женский | [ru_RU-irina-medium.onnx](https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx) | [ru_RU-irina-medium.onnx.json](https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx.json) |

3. Положите пару файлов рядом, сохранив имена. Для Дмитрия это `ru_RU-dmitri-medium.onnx` и `ru_RU-dmitri-medium.onnx.json`.
4. В Васе выберите Piper, укажите полный путь к `piper.exe` и `.onnx`. Номер диктора для этих моделей — **0**.
5. Нажмите **Послушать голос**, настройте громкость и скорость. Введите имя, например «Вася — Дмитрий», нажмите **Добавить свой пресет**, затем **Сохранить настройки**. Второй пресет может указывать на Ирину.

«Спокойный», «Обычный», «Энергичный» изменяют темп. Именованные пресеты сохраняют движок, модель/голос, номер диктора и темп. Громкость остаётся общей настройкой голоса.

Модели и конфигурации должны быть совместимы с выбранным исполняемым файлом. Смотрите модельную карточку и лицензию конкретного голоса в [каталоге Piper](https://huggingface.co/rhasspy/piper-voices/tree/v1.0.0/ru/ru_RU). Ни исполняемый файл Piper, ни голоса в установщик Васи не включены. Голоса Windows работают без дополнительных загрузок.
