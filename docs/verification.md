# Проверки реализации

В Linux-среде разработки выполнены:

- `npm run build`: TypeScript и production-сборка Vite проходят.
- `cargo test --manifest-path src-tauri/Cargo.toml --lib --no-default-features --locked`: **17 тестов проходят**. Проверяются границы слова активации, таймаут, маршрутизация команд, числа словами для громкости, настройки, HTTP-протоколы LM Studio/Ollama, отмена генерации и отсутствие вставки устаревшего текста.
- `cargo clippy --manifest-path src-tauri/Cargo.toml --lib --no-default-features -- -D warnings`: проходит без предупреждений.
- `cargo fmt --manifest-path src-tauri/Cargo.toml --check`: проходит.
- Проверка типов для `x86_64-pc-windows-msvc`: Windows API, CPAL, трей, глобальная клавиша и IPC Tauri компилируются. Для этой проверки использована временная копия с `tauri::test::mock_context` вместо генерации ресурсов приложения; упаковку и установщик она не проверяет.
- Chromium: вкладки интерфейса, примеры команд, явный режим предпросмотра, переключение провайдеров, поля Whisper, минимальная ширина 760 px. Ошибок JavaScript и горизонтального переполнения нет.
- Chromium с тестовым IPC: успех/ошибка переключения микрофона, перечисление устройств, сохранение настроек, список моделей и вывод результата. Это проверяет интерфейс и контракт IPC; Windows API в этих сценариях заменён заглушкой.
- `cargo run --manifest-path src-tauri/Cargo.toml --example check_llm --no-default-features --locked`: получен ответ о IPv6 от реального LM Studio на `http://198.18.0.1:1234`, модель `google/gemma-3-4b`.

Нативный запуск Windows с микрофоном, SAPI, медиасессиями и вставкой в приложения в этой среде недоступен. Автовоспроизведение на Яндекс Музыке/Spotify и YouTube также не проверялось с аккаунтом пользователя. Для этих функций предусмотрен [отдельный список приёмочных сценариев](windows-checklist.md).

Windows CI выполняет полную сборку приложения и установщика NSIS. Конфигурация CI добавлена в репозиторий; запуск workflow и получение установщика на удалённом Windows runner в рамках этой сессии не выполнялись.
