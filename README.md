# Вася для Windows

Голосовой помощник на Rust + Tauri 2 для Windows 10/11 x64.

## Установка

1. Откройте [GitHub Releases](https://github.com/H-P-Star/vasya-assistant/releases) этого репозитория и скачайте установщик **Vasya_*_x64-setup.exe** последней версии.
2. Запустите `.exe` и завершите установку. Установщик включает русскую модель Vosk, многоязычный Whisper, все нужные компоненты и автономный установщик WebView2. Rust, Node.js, Build Tools и PowerShell пользователю не нужны.
3. Откройте Васю из меню «Пуск»; выберите микрофон, нажмите **Проверить микрофон** и произнесите несколько слов.
4. Нажмите **Начать пользоваться**. Скажите **«Вася, громче»** или нажмите **Ctrl+Alt+Space** и скажите **«найди погоду»**.

До завершения первого запуска фоновое прослушивание выключено. Проверка микрофона включает его на две секунды и не выполняет команды. Если доступа нет, приложение покажет ошибку: разрешите доступ настольным приложениям к микрофону в параметрах конфиденциальности Windows.

Распознавание и диктовка работают без интернета. Музыкальные сервисы, поиск и YouTube требуют подключения к интернету. Для Яндекс Музыки/Spotify выберите сервис в настройках и нажмите **Открыть музыкальный сервис**; может потребоваться подписка. По умолчанию Вася использует установленное Windows-приложение.

## Команды

| Действие | После «Вася» или горячей клавиши |
|---|---|
| Музыка | включи трек Перемен / исполнителя Кино / плейлист Работа |
| Управление | пауза / продолжи / следующий трек |
| Громкость | громче / тише / громкость тридцать пять процентов |
| Поиск | найди в браузере что такое IPv6 |
| YouTube | включи видео о космосе на ютубе |
| Диктовка | диктуй Привет / начни диктовку → текст → стоп диктовка |
| Генерация | напиши, что такое IPv6 |
| Микрофон | отключи микрофон |

Генерация текста — дополнительная функция: установите LM Studio или Ollama обычным графическим установщиком, загрузите модель через их интерфейс, включите сервер и укажите адрес/модель в настройках Васи. Обычные команды не требуют LLM. Введённый адрес сервера сохраняется при обновлении.

Закрытие окна оставляет приложение в трее. Оттуда доступны включение/отключение микрофона и выход. Настройки находятся в `%LOCALAPPDATA%\Vasya` и сохраняются при обновлении приложения; модель лежит в папке установки. Для нестандартной модели можно задать пути в настройках; пустые пути выбирают встроенные компоненты.

Если встроенные файлы удалены или повреждены, переустановите полную версию приложения. Не требуется вручную искать DLL или запускать команды. Автовоспроизведение зависит от входа, подписки и версии клиента; помощник сообщает, если открыл только поиск.

## В 0.4.0

- **Калибровка речи:** отдельный мастер измеряет шум/уровень сигнала, проверяет «Вась/Вася» и русские/английские фразы. Выбранные варианты обращения и исправления сохраняются в персональном профиле. Модель не переобучается. Звук записывается только на время шага и не отправляется в облако.
- **Редактор встроенных команд:** во вкладке «Мои команды» доступны фразы, действие, содержимое, отключение и восстановление каждого встроенного правила. Стандартное «стоп диктовка» сохраняется как выход при активной диктовке.
- **Голоса:** выбор установленного голоса Windows, отдельная громкость и скорость, Piper по пути к `.exe`/`.onnx`, именованные мужские и женские пресеты. [Скачать совместимые голоса и настроить Piper](docs/voices.md).
- **Облачные LLM:** OpenRouter, OpenAI API и совместимый API с настраиваемым базовым адресом, моделью и ключом. Ключ защищён Windows DPAPI и хранится отдельно от settings.json. Подписка ChatGPT имеет отдельный учёт; некоторые тарифы предоставляют API-кредиты, но для Васи всё равно нужен API-ключ. [Официальное пояснение OpenAI](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform).
- **Остров:** компактная чёрная панель появляется при явном вызове словом/клавишей. Обычные события журнала её не открывают. Ответ модели раскрывается прямо из панели в карточку с прокруткой и копированием; он остаётся до закрытия. Кнопка × и Escape закрывают панель и отменяют текущую обработку/озвучивание. Последний текст доступен в основном окне и по кнопке «Открыть в панели».
- **Яндекс Музыка:** разбор названия и исполнителя, выбор подходящего результата, проверка реального состояния плеера и восстановление подключения после перезапуска Васи. Пример: «включи трек Перемен исполнителя Кино». Если клиент открыт без управления, в настройках нажмите **Перезапустить и подключить Яндекс Музыку** — это остановит текущую музыку.
- **«Вась» и английские слова:** отдельный грамматический детектор обращения использует ту же модель Vosk; личные варианты добавляются через калибровку. Для английских названий выберите **Vosk + Whisper** и язык **Автоматически**. Whisper и многоязычная base-модель входят в установщик. Существующие настройки Vosk сохраняются; мастер калибровки может переключить их на Whisper. Точность зависит от микрофона, произношения и модели; путь к другой многоязычной модели можно указать вручную.

Whisper выбирает оптимизированный CPU-бинарник автоматически; для процессоров без AVX2 предусмотрен совместимый вариант. На старых CPU распознавание Whisper может быть медленным — для коротких русских команд можно оставить Vosk. При сборке Whisper компилируется из исходников со статическим C++ runtime, поэтому Visual C++ Redistributable не нужен на компьютере пользователя.

## Возможности 0.3.0

**Музыка в приложении.** В настройках доступны Яндекс Музыка, Spotify и браузерный режим. Официальный клиент Яндекса автоматически ищется в `%LOCALAPPDATA%\Programs\YandexMusic\Яндекс Музыка.exe`. Для другой установки укажите полный путь в разделе «Пути к музыкальным приложениям». Команда «включи музыку» открывает выбранный сервис; «открой Яндекс Музыку» и «открой Spotify» открывают указанный сервис.

Яндекс Музыка управляется через локальное подключение к официальному Electron-клиенту. Первое подключение можно подготовить кнопкой перезапуска в настройках. Поиск выполняется внутри приложения; результат выбирается по названию и исполнителю, воспроизведение проверяется по состоянию плеера. Вход и подписка остаются в обычном профиле. Выход из Васи оставляет музыкальное приложение работающим.

Spotify открывает поиск в своём приложении через `spotify:search`; выбор результата и первый запуск воспроизведения пока выполняются вручную. Пауза, продолжение и следующий трек работают через медиасессию Windows. YouTube и обычный поиск открываются в браузере по умолчанию. Браузерный музыкальный режим использует отдельный профиль Edge/Chrome.

**Мои команды.** Добавляйте и меняйте фразы в отдельной вкладке. Можно назначить трек, исполнителя, плейлист, поиск, видео, генерацию, вставку, готовый ответ, открытие `.exe`, громкость или управление воспроизведением. Пример: фраза `поищи {query}`, действие «Поиск в браузере», содержимое `{query} официальный сайт`. Параметр допускается один раз, в середине или в конце фразы. Для запуска `.exe` используется только постоянный путь, без аргументов или shell.

Точные свои фразы имеют приоритет над шаблонами, более длинный шаблон — над коротким. Чтобы изменить встроенную команду, создайте правило с той же фразой. Действие «Не выполнять эту фразу» блокирует её; удаление правила или снятие галочки возвращает встроенное поведение. «Стоп диктовка» остаётся командой выхода из диктовки; остальные фразы во время диктовки вставляются как текст.

**Панель активации.** Прозрачная панель в стиле Dynamic Island появляется сверху основного экрана при слове активации или горячей клавише, показывает уровень микрофона и этап обработки. Она не принимает фокус; кнопки управления и копирования работают внутри панели. Панель можно отключить в настройках. Частичная гипотеза детектора показывает панель заранее; команды выполняются по окончательному распознаванию.

**Неизвестные команды → LLM.** Включённый параметр «Обращаться к модели, если команда не распознана» отправляет фразу на настроенный LM Studio/Ollama. Модель выбирает одно разрешённое действие помощника либо отвечает на вопрос. Ответ отображается в результате и озвучивается при включённом подтверждении; сам по себе ответ не вставляется в активное поле. Явные запросы «пиши/напиши» сохраняют режим генерации с вставкой. Произвольные программы и shell-команды модель запускать не может. Без запущенного сервера неизвестная фраза выдаст понятную ошибку; встроенные и свои команды продолжают работать без LLM.

## Сборка и выпуск (для разработчиков)

На машине сборки Windows с Rust/MSVC, Node.js 22, CMake и C++ Build Tools выполните `scripts/build-windows.ps1`. Скрипт подготовки получает фиксированные архивы Vosk, проверяет SHA256 из `scripts/speech-assets.json` и включает DLL/модель в NSIS-пакет. Тексты лицензий распространяются вместе с приложением.

Для релиза выставьте одинаковую версию в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`, обновите Cargo.lock и отправьте тег `v<версия>`. Workflow **Windows release** проверяет версии, собирает x64 NSIS, устанавливает его в отдельную папку и проверяет загрузку Vosk из установленной копии с чистым профилем. Только после успешной проверки `.exe` и SHA256SUMS публикуются в GitHub Releases.

Полная Windows-сборка/публикация выполняется в GitHub Actions; конфигурация workflow сама по себе не означает, что релиз уже опубликован. Подпись Authenticode требует сертификата издателя и пока не настроена; Windows может показывать «Неизвестный издатель».
