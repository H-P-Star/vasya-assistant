# Вася

Локальный голосовой помощник для Windows 10/11 x64. Ядро написано на **Rust**, окно настроек — **Tauri 2 + TypeScript**. Python для запуска не нужен.

[Предпросмотр интерфейса](docs/preview.png) · [Проверки](docs/verification.md)

## Возможности

- Активация по «Вась» / «Вася», своему слову или нескольким фразам, по глобальной горячей клавише, либо обоими способами.
- Локальное распознавание Vosk; дополнительное уточнение активированных фраз через локальный `whisper-cli.exe` из whisper.cpp.
- Музыкальный поиск по треку, исполнителю и плейлисту: Яндекс Музыка, Spotify, YouTube. Для Яндекса и Spotify — попытка запуска через отдельный профиль Edge/Chrome и проверка признака воспроизведения.
- Пауза, продолжение и следующий трек через текущую медиасессию Windows; системная громкость от 0 до 100% и шаг ±10%.
- Поиск в браузере по умолчанию; поиск первого видео YouTube и открытие страницы воспроизведения.
- Разовая и непрерывная диктовка в активное приложение через Unicode `SendInput`, без изменения буфера обмена.
- Отдельная команда «пиши/напиши» для генерации через LM Studio или Ollama с последующей вставкой. Обычные команды не требуют LLM.
- Трей, индикатор использования микрофона, уровень звука, отключение микрофона, локальное голосовое подтверждение Windows SAPI.
- Редактируемый результат и отложенная ручная вставка, если фокус приложения изменился.

Это исходный MVP. Сборка интерфейса и тесты ядра проверяются отдельно от ручных сценариев Windows. Работа конкретных микрофонов, SAPI, автозапуска сайтов и браузерных селекторов требует проверки на целевом компьютере; см. [приёмочные сценарии](docs/windows-checklist.md).

## Запуск из исходников на Windows

Для разработки нужны актуальный стабильный Rust с MSVC, Node.js 22 LTS, Microsoft C++ Build Tools с компонентом **Desktop development with C++** и WebView2. Это [требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/). Пользователю собранного приложения Rust, Node и Build Tools не нужны; установщик при необходимости устанавливает WebView2.

```powershell
npm ci
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-models.ps1
npm run tauri dev
```

Скрипт подготовки скачивает DLL из [официального релиза Vosk](https://github.com/alphacep/vosk-api/releases/tag/v0.3.45) и небольшую [русскую модель](https://alphacephei.com/vosk/models). По умолчанию они размещаются в `%LOCALAPPDATA%\Vasya`. Скачивание — отдельное явное действие, при старте помощник ничего не загружает. Можно скачать архивы вручную и указать свои пути в настройках. DLL и её зависимости должны находиться в одной папке; выбирайте доверенную сборку x64.

После запуска:

1. Выберите микрофон. Windows должна разрешать доступ к микрофону настольным приложениям.
2. Сохраните настройки. Это перезапустит распознавание без перезапуска приложения.
3. Для Яндекс Музыки/Spotify выберите сервис, сохраните настройки и нажмите **Войти в сервис**. Вход выполняется в отдельном профиле браузера, обычный профиль не используется.
4. Скажите «Вася, пауза» либо нажмите `Ctrl+Alt+Space` и произнесите команду. Можно сначала сказать «Вася», затем дождаться индикатора приёма команды и продолжить.

Закрытие окна оставляет приложение в трее. Завершение — пункт **Выход** в трее. Настройка «Открывать сразу в трее» действует при следующем запуске; автозапуск вместе с Windows пока не добавлен.

## Генерация текста

По умолчанию настроен ваш **LM Studio**:

- Провайдер: `lm_studio`.
- Адрес: `http://198.18.0.1:1234` (без `/v1`).
- Модель: `google/gemma-3-4b`.

Оставьте Local Server в LM Studio запущенным. В настройках есть **Проверить соединение**: помощник запросит список моделей. Генерация использует [совместимый API LM Studio `/v1/chat/completions`](https://lmstudio.ai/docs/developer/openai-compat/chat-completions). Python SDK и облачный аккаунт не нужны.

Альтернатива — [Ollama](https://ollama.com). Выберите провайдер Ollama, укажите `http://127.0.0.1:11434` и имя установленной модели, например:

```powershell
ollama pull qwen2.5:3b
```

Для Ollama используется [API `/api/generate`](https://docs.ollama.com/api/generate). В обоих вариантах модель не получает инструменты, доступ к файлам или выполнение кода. Результат ограничен 1024 токенами, ожидание — 90 секунд.

Поставьте курсор в поле приложения и скажите: **«Вась, напиши, что такое IPv6»**. Текст вставится, если активное окно осталось тем же. При смене окна результат сохраняется в интерфейсе. Ввод команды в строке самого помощника показывает результат без автоматической вставки.

Можно указать другой HTTP(S)-сервер с выбранным API. **Текст явно запрошенной генерации** отправляется на указанный сервер, аудио — нет. Встроенных облачных STT-провайдеров и хранения API-ключей в MVP нет.

Проверка реального подключения из Rust без запуска интерфейса (использует значения по умолчанию):

```powershell
cargo run --manifest-path src-tauri/Cargo.toml --example check_llm --no-default-features
```

## Режим Whisper

Скачайте Windows-сборку [whisper.cpp](https://github.com/ggml-org/whisper.cpp/releases), её зависимости и многоязычную ggml-модель, например `ggml-base.bin`. Выберите режим **Vosk + Whisper**, укажите `whisper-cli.exe` и файл модели. Исполняемый файл и DLL берутся из одной сборки; английские модели с суффиксом `.en` не подходят для русского.

Vosk по-прежнему определяет активацию и границы фраз. Whisper уточняет только уже принятые фразы, включая диктовку; в режиме ожидания он не запускается. Максимальная фраза — 30 секунд, для длинной диктовки делайте паузы. Для каждого уточнения создаётся временный WAV 16 кГц mono PCM, который удаляется после обработки. При принудительном завершении процесса временные файлы могут остаться в системной временной папке.

## Примеры команд

После слова активации либо горячей клавиши:

| Задача | Команда |
|---|---|
| Трек | `включи трек Перемен` |
| Исполнитель | `включи исполнителя Кино` |
| Плейлист | `включи плейлист Работа` |
| Воспроизведение | `пауза`, `продолжи`, `следующий трек` |
| Громкость | `громче`, `тише`, `громкость 35 процентов` |
| Поиск | `найди в браузере что такое IPv6` |
| YouTube | `включи видео о космосе на ютубе` |
| Вставка сказанного | `диктуй Привет, Анна` |
| Непрерывная диктовка | `начни диктовку`, затем фразы без слова активации |
| Завершить диктовку | `стоп диктовка` или горячая клавиша |
| Генерация | `напиши, что такое IPv6` |
| Отключение | `отключи микрофон` |

Во время непрерывной диктовки команды, кроме завершения, вставляются как обычный текст. Чтобы включить отключённый микрофон, используйте кнопку или трей: голосом это сделать нельзя. Отключение освобождает поток захвата и отменяет ожидающую вставку; в режиме только горячей клавиши микрофон освобождается и между командами.

## Ограничения интеграций

- Слова активации проверяются по началу финальной фразы Vosk, это обычное ASR, а не специализированный wake-word движок. Произвольное слово должно присутствовать в словаре выбранной модели; короткое «Вась» может распознаваться хуже «Вася». Горячая клавиша позволяет работать без ожидания слова.
- Яндекс Музыка/Spotify требуют интернета, входа, доступности сервиса и иногда подписки. Структура сайта меняется. Адаптер пытается нажать воспроизведение и проверить media element / Media Session; если подтвердить запуск не удалось, он сообщает, что открыт поиск. Совпадение первого результата не гарантирует точного совпадения версии трека.
- Музыкальный профиль управляется по CDP через случайный порт на loopback и закрывается с помощником. Он содержит cookies аккаунта. Не используйте его для посторонних сайтов. Обычные браузерные профили помощник не подключает.
- YouTube может требовать согласие на cookies, CAPTCHA, вход и ручной запуск из-за autoplay-политики. При недоступности извлечения первого результата открывается поисковая выдача. YouTube и общий поиск используют браузер по умолчанию.
- Медиакоманды относятся к **текущей медиасессии Windows**, а не обязательно к последнему открытому музыкальному сервису. Плеер должен публиковать медиасессию и поддерживать нужное действие. Пауза и продолжение вызываются раздельными методами, не переключателем.
- `SendInput` поддерживается большинством стандартных текстовых полей (например, Блокнот, браузер, офисные приложения), но не всеми играми/защищёнными приложениями. Ввод в программу с повышенными правами может быть отклонён Windows. В защищённые поля диктовать не следует. Права администратора помощнику обычно не нужны.
- Переносы строк и табуляция передаются как Unicode-символы, без эмуляции клавиш Enter/Tab. Некоторые нестандартные поля могут их игнорировать; для них используйте копирование результата и обычную вставку приложения.
- Русское голосовое подтверждение зависит от выбранного голоса Windows SAPI. Установите русский голос в Windows; при отсутствии подходящего голоса используйте визуальный статус или выключите озвучивание.

## Данные и расширение

В `%LOCALAPPDATA%\Vasya` находятся `settings.json`, резервная копия `settings.bak`, модели и `browser\edge` / `browser\chrome`. История команд и результат находятся в памяти окна, постоянного журнала распознанного текста нет. Для восстановления после неверного JSON исправьте или переименуйте файл настроек; приложение не перезаписывает его при чтении ошибки.

Можно добавить точные псевдонимы в массив `aliases` файла настроек и перезапустить приложение:

```json
"aliases": [
  {"phrase": "мой трек", "action": "music", "payload": "Кино Перемен"},
  {"phrase": "рабочий поиск", "action": "search", "payload": "документация Rust"}
]
```

Разрешены `music`, `youtube`, `search`, `generate`, `insert`, `pause`, `resume`, `next`, `mute`. Псевдонимы не выполняют shell-команды. В коде новые действия добавляются в `commands::Command` и исполнитель `runtime`; музыкальные интеграции реализуют `browser::MusicService`. Подробнее — [архитектура](docs/architecture.md).

## Проверка и сборка

```powershell
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib --locked
npm run tauri build
```

Или `powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1`. Установщик NSIS появится в `src-tauri\target\release\bundle\nsis`. Модели загружаются отдельно, в установщик не включены. CI содержит отдельную сборку Windows и загрузку установщика как артефакта; автоматического релиза нет.

На Linux доступны тесты платформонезависимого ядра: `cargo test --manifest-path src-tauri/Cargo.toml --lib --no-default-features`. `npm run dev` открывает только предпросмотр интерфейса; функции ОС и сохранение настроек в браузере отключены. Контейнер не выбран как основной вариант: доступ к интерактивному рабочему столу, микрофону, трею и вводу Windows требует нативного процесса в пользовательской сессии.
